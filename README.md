# Salgyn_Park
Лендинг для Салгын Парка

## Фото и видео
1. Фото/видео от менеджера кладём в `incoming/` под нужными именами (ниже).
2. `pip install pillow` → `python convert_media.py`
3. Результат появляется в `images/`. Его коммитим, сайт подхватывает сам.

| Что | Имя файла |
|---|---|
| Фон главного экрана | `hero` |
| Услуги | `aerotruba`, `batut`, `labyrinth`, `vr-arena`, `ps5`, `arcade`, `spiderman`, `vr-stand`, `certificate` |
| VIP-комнаты | `zemlya`, `voda`, `vozduh`, `ogon`, `metall` |
| Второе фото (появляется при наведении/тапе) | то же имя + `-2`, например `aerotruba-2` |

Если фото нет, на карточке остаётся цветной градиент.
Видео: основной формат MP4 (H.264), запасной WebM; WebP для видео не подходит (только для обложки).
